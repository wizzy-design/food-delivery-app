## ✨ Features

- **Dynamic Homepage**: Browse categories and trending meals with smooth horizontal scrolling.
- **Premium Food Details**:
  - Interactive topping & side selection.
  - Real-time price calculation based on quantity and extras.
  - High-performance image rendering using `expo-image`.
- **Advanced Cart System**:
  - Live quantity adjustment.
  - One-tap delete.
  - Interactive "Order Success" modal flow.
- **Authentication**: Secure login and signup powered by Supabase Auth.
- **Modern UI/UX**: Built with NativeWind (Tailwind CSS) for a responsive, premium look and feel.

## 🏗️ Getting Started

### Prerequisites

- Node.js
- Expo Go app on your phone (for testing)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/wizzy-design/food-delivery-app.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up environment variables:
   Create a `.env.local` file and add your Supabase credentials:
   ```env
   EXPO_PUBLIC_SUPABASE_URL=your_url
   EXPO_PUBLIC_SUPABASE_ANON_KEY=your_key
   ```
4. Start the development server:
   ```bash
   npx expo start
   ```
